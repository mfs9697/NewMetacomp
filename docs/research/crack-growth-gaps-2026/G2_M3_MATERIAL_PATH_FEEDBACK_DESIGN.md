# G2-M3 research design — material-specific paths and path-feedback decomposition

**Status:** prospective, **NO new G2-M3 MATLAB simulations**. **Date:** 2026-11-21. Scientific issue [#39](https://github.com/mfs9697/NewMetacomp/issues/39). Complete Claude instruction `matlab/g2/CLAUDE_G2_M3_MATERIAL_PATHS_PROMPT_ISSUE39.md`. Parent verified draft [PR #38](https://github.com/mfs9697/NewMetacomp/pull/38) `49ec4fc6867c5be70e18f9c6b79db708190e3aa9`, untouched.

## Core physical question

On a three-hole Cornell-type plate with **perfectly bonded soft or stiff reinforcement bands**, the previous material study showed that direct changes in elastic crack-driving force and in the MTS direction need not correlate. If the crack is allowed to follow a material-specific numerical MTS trajectory, does the **changed trajectory itself** increase or decrease the net elastic driving force?

This is a numerical *conditional path given assumed two 4-mm extensions*, not a fracture-onset or physical trajectory validation study.

## Three paths and three values of G at each arclength

- `Γ_H(s)`: existing independently qualified **homogeneous** numerical MTS path at s=25.4,29.4,33.4mm.
- `Γ_M(s)`: NEW, **independently meshed + freshly solved** two-phase material path for each `M∈{soft,stiff}` at those same arclengths.
- `G_H[Γ_H](s)`: existing homogeneous reference tip driving force.
- `G_M[Γ_H](s)`: existing frozen-path *material-only* counterfactual from the verified G2-M2/PR #38.
- `G_M[Γ_M](s)`: new actual elastic two-phase tip result on the geometry **selected by that material** at its previous step.

Define

`R_direct^M(s)=G_M[Γ_H](s)/G_H[Γ_H](s)`,

`R_path^M(s)=G_M[Γ_M](s)/G_M[Γ_H](s)`,

`R_total^M(s)=G_M[Γ_M](s)/G_H[Γ_H](s)`,

with the non-negotiable identity `R_total = R_direct R_path`.

**Interpretation:** `R_direct` captures material substitution at a frozen crack shape; `R_path` captures geometry feedback *within the same material*; `R_total` captures both. These definitions do not compare hole/no-hole cases and must not be conflated with the earlier G2 perforation-specific `R_direct` definition.

**Baseline s=25.4mm:** same Γ for every material, hence `R_path=1` exactly. At s=29.4/33.4mm, the new independently evolved `Γ_M` must have its own signed MTS from its own parent SIF and freshly generated protected mesh. The existing homogeneous State 1/2 geometries are read-only comparison controls, not seeds for `Γ_M`.

## Prior evidence and hypotheses (NOT new numerical outcomes)

Frozen homogeneous paths: 

| s (mm) | R_direct soft | R_direct stiff | Direction shift soft (deg) | Direction shift stiff (deg) |
|---:|---:|---:|---:|---:|
| 25.4 | 0.99391 | 0.99096 | +0.647 | −0.425 |
| 29.4 | 1.00620 | 0.98187 | +0.743 | −0.493 |
| 33.4 | 1.02181 | 0.97069 | +0.694 | −0.452 |

These prior data were generated by re-solving **each material on the same frozen homogeneous crack** within each state, not by material-specific propagation. Main paired-estimator uncertainty resolves differences, conservative uncorrelated ±3.5% does not; preserve both. Refined S2 alternative mesh changes the material-only δR by only about 0.07% of δR.

*Possible G2-M3 findings*:
1. `R_path≈1` within path/separation uncertainty: material direct effect persists, numerical path feedback negligible.
2. `R_path>1`: the steered path amplifies the total driving force relative to the material on the reference path.
3. `R_path<1`: geometry feedback provides additional screening.
4. `R_path` changes the sign of `R_total−1` relative to `R_direct−1`: the material steers its crack into a different energy regime.
5. A numerically differing path is **not robustly distinguishable** from mesh/estimator uncertainty: report unresolved, not an invented mechanism.

**Preliminary first-step angle forecasts only:** homogeneous −12.596°, soft −11.949°, stiff −13.020° (in S0 terminal frame). Actual first tips require full-precision source K and audited fresh geometry.

## Mandatory experimental methodology

Separate **Msoft** and **Mstiff** chains, each initialized from the accepted S0 model with *its own* material-specific SIF, two steps only, new protected mesh + independent 34/34 saved-array audit and 3-hole bonded phase-map verification at **every** new tip. Original numerical p010, collar, 64+64 seams, 2,443 q-active parents, 20°/1.8 mesh quality, ≤40k T3 budget, 5GiB free RAM, source SHA, clean MATLAB R2023a and all SIF/COD/EDI gates remain unchanged. Whole q support stays within matrix. New material policy preregistered *before* observations and authorizes max two steps/33.4mm, never edits earlier trajectory v1.

Preserve signed orientation: MTS is a **local tangent-frame** angle. For path comparisons report true global tip positions, a consistent common reference-axis signed lateral deviation, total separation and parent-frame turning angles; don't directly accumulate or compare local angles as if global.

Each accepted step has a source-locked REVIEW before State with complete mesh, polygon phase map, material ID, source/policy SHA and independent saved-array re-audit. Valid review/state can be reused only after full verification, never by manifest alone. Interruption, tampering and corrupt phase negatives must refuse promotion without new FEM.

**Physical/model limits:** identical idealized 1N pin/roller BVP, plane stress, illustrative `E_r/E_m=.5/2` and perfectly bonded interfaces; no calibrated polymer–cement data, toughness, CZM, contact/delamination, actual physical growth, or Cornell experiment path claims.

## Decision

The bounded two-step M3 campaign succeeds scientifically if it provides either **independently qualified material-specific numerical trajectories and an uncertainty-conscious decomposition**, or a well-documented numerical HOLD showing why the effect cannot yet be resolved. No need to force a visual crack-path difference or a dramatic G value. Any future longer path, interface break or physical fracture work requires a separate versioned programme.
