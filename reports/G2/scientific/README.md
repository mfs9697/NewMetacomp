# Науковий звіт G2 — LaTeX

Редакційний каркас, незалежний від обчислювальних гілок. Не є готовим науковим звітом. Жодних нових розрахунків або затверджень.

## Компіляція (Windows PowerShell 5.1 / PowerShell 7)

З кореня репозиторію:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\reports\G2\scientific\scripts\Build-Report.ps1
```

Потрібні XeLaTeX, пакети з preamble.tex, шрифти Libertinus Serif/Sans/Mono/Math; Biber потрібен тільки після увімкнення бібліографії. У MiKTeX встановіть пакети заздалегідь, щоб уникнути інтерактивних діалогів. Скрипт виконує три проходи XeLaTeX у batchmode, запускає Biber за потреби, перевіряє коди завершення та фінальний лог. Результат: build/main.pdf; build/main.log — лог. Каталог build ігнорується Git. При невдачі попередній PDF не залишається під канонічним ім'ям.
